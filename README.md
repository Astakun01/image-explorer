# 🖼️ Image Explorer

A modern image discovery application built with React and Vite that allows users to explore images from multiple APIs through a clean and interactive interface.

## ✨ Features

- 🖼️ Browse images from multiple sources
- 🔍 Search for images
- 🎌 Explore anime images
- 📄 Navigate images using pagination
- 👀 View images on a dedicated details page
- 🔄 Restore gallery state when navigating back
- ⏳ Loading indicators and error handling
- 📱 Responsive user interface

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Axios
- React Router
- REST APIs

## 🌐 APIs Used

- **Picsum Photos** — Browse random images.
- **Nekos.best** — Explore anime-style images.
- **Pixabay API** — Search for images.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Astakun01/image-explorer.git
```

### 2. Navigate to the project folder

```bash
cd image-explorer
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

If your Pixabay API key is stored in an environment variable, create a `.env` file in the project root and add the required variable.

Never upload API keys or secrets to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
